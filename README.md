# Brrr. Slush Co.

A concept website for a made-up Manchester slush bar, designed and built by [Sama Eldesouki](https://sayrz1.github.io).

**Live demo:** https://sayrz1.github.io/brrr/

- A real-time 3D cup (Three.js) that changes flavour, colour and fruit as you scroll
- Scroll-pinned flavour picker, a two-flavour "mystery cup" you can shake, a menu with sizes and prices
- Shop finder with a map, area filters and live UK opening hours
- Smooth scrolling with GSAP ScrollTrigger and Lenis, with a full reduced-motion fallback

Plain HTML, CSS and JavaScript. No build step: open `index.html` through any static server.

Brrr. is a fictional brand. Shop locations are real streets used for illustration only.
